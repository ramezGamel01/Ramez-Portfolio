Rihla A booking site with no JavaScript.

A multi-page bus booking site for travel around Egypt: trip search, seat selection, a three-step checkout and a bookings dashboard, built with HTML and CSS only.

The problem

A booking flow is usually where a site reaches for JavaScript: picking seats, keeping a running total, and enabling the next step only once something is selected.

Rihla does all of that in HTML and CSS. The pages work with scripts turned off, load fast, and every control is a real form element that keyboards and screen readers already understand.

What it does

  • A home page with trip search, popular destinations and responsive navigation.
  • A trips list with a filter panel for destination, price and duration, and sort options.
  • A seat map: pick seats and the count and total price update, and Book Now becomes active.
  • A three-step checkout: trip summary, passenger details, then review and pay.
  • A bookings dashboard with confirmed, pending, completed and cancelled trips, each with its own page.
  • Sign-in, sign-up, verification and password recovery pages.

How it's built

Semantic HTML and five stylesheets: a shared one, and one each for booking, sign-in, sign-up and password pages, all built on the same CSS custom properties for colors, fonts and corner radii. Layouts use Grid and Flexbox, with breakpoints from desktop down to 400 pixels wide.

Decisions that shaped it

Seats are real checkboxes

Each of the 40 seats is a checkbox with a label, and reserved seats are disabled. Selecting works with a mouse, a finger or the keyboard, and the browser keeps track of the state.

Totals from CSS counters

Every checked seat increments two CSS counters, one for the count and one for the price, and the summary prints them with counter(). The total updates the moment a seat is picked, with no script.

:has() for the rest of the form

The form uses :has(:checked) to show the summary, the seat badge and an active Book Now button only when at least one seat is selected.

Counters follow page order

A CSS counter only includes elements that come before it in the markup, so the badge above the seat map always read 0. I moved it after the seats in the HTML and positioned it back at the top of the card, and now it shows the real count.

One set of design tokens

Every stylesheet uses the same custom properties for colors, fonts and radii, so the booking, account and password pages look like one product.
